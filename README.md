# global-affiliate

Source for **Useful Work Tools**, an independent English-language publication about AI tools, productivity, software, automation, digital tools, and the future of work.

## Publishing

The site is a dependency-free static build served by GitHub Pages from the repository root.

- Production URL: https://pgrootoffice-dev.github.io/global-affiliate/
- Pages source: `main` / root
- Local preview: `python3 -m http.server 8000`

## Editorial principles

The publication prioritizes practical reader value, accurate and appropriately scoped claims, clear affiliate disclosure, visible corrections, and independence from commercial relationships. See `PROJECT.md` and `editorial-policy.html` for the full operating context.

## Structure

- `index.html`: home and featured guides
- `assets/styles.css`: shared mobile-first design system
- article HTML files: original editorial guides
- `about.html`, `editorial-policy.html`, `disclosure.html`, `privacy.html`, `contact.html`: trust and policy pages
- `robots.txt`, `sitemap.xml`: discovery metadata

No analytics, advertising scripts, cookie tracking, external fonts, or fabricated affiliate links are included.
